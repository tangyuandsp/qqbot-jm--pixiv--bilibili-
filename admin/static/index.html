🎨 AI 绘图 & 图片理解 使用说明
🖼️ 文生图：/draw 一只猫在樱花树下
✏️ 图生图：引用图片消息 + 直接发要求（群聊需 @机器人），如「把头发染成粉色」
💠 千问引擎：引用图片 + 描述含「千问」，如「千问把背景改成夜景」
🔍 高清化：引用图片 + 「高清化」→ 输出 2K 高清版
👀 图片理解：引用图片 + 提问（这是啥/谁/出自哪），AI 看图回答
📐 比例：默认保持原图比例；提示词可指定 16:9 / 1920x1080 / 方形 / 横版 / 竖版
